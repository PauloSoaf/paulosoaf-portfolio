# ADR-003: conteúdo estático tipado e revisado

Status: Proposed. Contexto: portfólio não requer backend para primeira versão.

Decisão: fontes de verdade em arquivos TypeScript/Markdown locais tipados, filtrados por status aprovado. Links de demos só após verificação manual. Sem chamadas GitHub em runtime essenciais ao funcionamento.

Consequências: deploy barato e previsível, atualizações via commit, trabalho editorial explícito.

Reavaliar se: escala de cases ou múltiplos editores justificar CMS.
