# Definition of Done

Toda sprint concluída inclui:
- [ ] Código versionado, padrões e tokens sem duplicação desnecessária.
- [ ] RF/RNF/AC rastreados e relatório de evidências criado.
- [ ] `lint`, `typecheck`, `test`, `build` passam (ou bloqueio formalmente registrado, sem declarar pronto).
- [ ] Screenshot desktop 1440x900 e mobile 390x844 anexadas ao relato da sprint.
- [ ] Testes teclado, reduced motion, mobile, mídia quebrada e falha WebGL quando relevantes.
- [ ] Links, dados e permissões revisados (não inventar informações).
- [ ] Documentos/ADRs atualizados quando decisão mudou.
- [ ] Nenhum componente anterior regrediu sem causa registrada e aceite explícito.
- [ ] CTA principal funciona e permanece legível em toda largura de tela.
